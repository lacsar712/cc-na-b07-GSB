# 航标灯光巡检台

登记航标实测光强和方位偏差，服务端当场给出合格或不合格。页面由 Django 模板直接渲染，浏览器不另跑一套单页应用。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3190 |
| 应用 | http://localhost:8190 |
| PostgreSQL | localhost:54390 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| keeper | light123456 | 可登记 |
| watch | watch123456 | 只读 |

## 启动

```bash
cd projects/11-nav-aid-inspection
docker compose up --build
```

## 验收

1. 打开 http://localhost:3190 ，用 keeper 登录，默认总表只剩偏暗的 LH-09（不合格）；明亮合格种子 LH-01 已交卷封存。
2. 打开封存册，能看到 LH-01 的封存原因、封存人 keeper 与封存时刻。
3. 进入 LH-09 详情，尝试封存会提示不合格记录不能封存；对 LH-01 提交亮度改正，服务端拒绝且数值保持 1400 不变。
4. 换 watch 登录，能读封存册但没有登记/封存/改正入口；直接 POST 这些操作返回 403。
5. keeper 登记一条合格记录、填写原因封存后，该记录从总表消失、出现在封存册；封存不填原因会被拒绝。
